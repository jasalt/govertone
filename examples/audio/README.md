## Test fixtures

- `issue-15-nrepl-a4-validation.mp3` — two-second offline render triggered by a raw nREPL `(play :sine :a4 {:at 0 :dur 1})` request. Generated by `TestNREPLPlayRendersAudio` using the real Sointu engine, then converted from float WAV with `ffmpeg -codec:a libmp3lame -q:a 4`.
- `issue-8-exact-control-step.mp3` — `testdata/controls/exact-step.lg`; note-local velocity applies at frame 0 and instrument gain steps from 24 to 96 at frame 22050. Converted from the `make test-controls` float WAV with the same ffmpeg settings.
- `issue-9-linear-automation.mp3` — `testdata/automation/linear-ramp.lg`; a sample-accurate linear gain ramp from 20 to 100 over frames 0–44100. Converted from the `make test-automation` float WAV.
