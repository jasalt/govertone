# Control buses

Buses are documented with the other named controls, in
[controls.md § Control buses](controls.md#control-buses). That section covers
declaration (`defbus`), mappings and transforms (`map-control!` with
`:scale`/`:offset`), automation (`bus-set!`, `bus-ramp`), patch migration,
and inactive mappings. For ramp curves and timing see
[automation.md](automation.md).
